# ライフプラン・シミュレーター

手取り収入・生活費・インデックス投資・高配当株投資を年齢や時期ごとに設定して、生涯の資産推移を**月単位**でシミュレーションできる無料ツールです。

**▶ 使ってみる: https://takashikatsuhara.github.io/lifeplan-simulator/**

## 特徴

- 手取り・生活費・投資額をそれぞれ独立したタイミング（〜◯歳の◯月まで）で設定できるフェーズ制
- インデックス投資（年利）と高配当株投資（値上がり率＋配当利回り）を分けてシミュレーション
- 老後の取り崩しに対応：現金 → インデックス → 高配当の順に自動売却。定額・定率（4%ルール）も設定可能
- ボーナス一括投資・退職金・車の購入などの単発イベント（メモ付き）
- 資産推移の積み上げグラフ、ライフプラン年表、プラン比較
- 入力データはブラウザ内（localStorage）にのみ保存。サーバー送信なし。JSONでバックアップ・復元可能

## 免責事項

本ツールはシミュレーションによる情報提供のみを目的としており、投資助言・勧誘ではありません。計算は簡易的なモデル（月次複利、税金・手数料は未考慮）に基づくものであり、将来の運用成果を保証するものではありません。詳細はページ内の免責事項をご覧ください。
